# Dark Blue Moon Stand Addon

A JoJo Stand addon for [Ripples of the Past](https://www.curseforge.com/minecraft/mc-mods/ripples-of-the-past) Minecraft mod.

This addon adds the **Dark Blue Moon** Stand to Ripples of the Past.

## Features

- Dark Blue Moon Stand with custom model
- Chop, Barrage, Heavy Attack, Light Attack
- Scale Shot (normal & focused)
- Barnacle skills (bind, self-bind, pull, trap)
- Whirlpool
- Barnacle items (meat, shell, necklace, cooked variants)
- Custom crafting & cooking recipes
